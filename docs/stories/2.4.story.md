# Story 2.4: Refactor Task Module Following CRM Deal Module Architecture

## Status
Approved

## Story
**As a** developer,
**I want** to refactor the task module to align with the established CRM Deal module architecture patterns,
**so that** the codebase maintains consistency and follows best practices across all business modules.

## Acceptance Criteria
1. DTO Alignment: Ensure task DTOs follow Deal DTO patterns for consistency across the system
2. Repository Layer Refactoring: Restructure task repository to match Deal repository patterns (`project/crm/deal/repository/pg_deal.go`)
3. Use Case Layer Alignment: Update task use case to match Deal use case patterns with enhanced business logic
4. Handler Layer Enhancement: Refactor task handler to follow Deal handler structure with proper operation naming and documentation
5. MCP Integration: Implement comprehensive MCP handler following Deal MCP pattern with all CRUD operations
6. Module Integration: Update module.go to follow Deal module's DI pattern and service registration
